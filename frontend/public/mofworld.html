Results

Every model, tuned the same way, on the same test MOFs. Higher R² is better.

tree / no graphGNN, no edgesGNN with graphlinear
Take-away: the best model uses no graph. A GNN with no edges is as good as any GNN with a graph; graphs built from language-model embeddings add nothing on top of fingerprints and pore columns.
