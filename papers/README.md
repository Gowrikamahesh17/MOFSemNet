# Literature

Papers collected during literature review, kept alongside a short notes file per paper so
citations stay traceable back to *why* a paper was cited, not just that it was.

## Convention

- Drop the PDF directly in this folder: `papers/<author-year-shortkey>.pdf`
  (e.g. `papers/jalali-2023-blackhole.pdf`).
- Add a matching notes file in `papers/notes/<author-year-shortkey>.md` using
  `papers/notes/_template.md`.
- Keep the shortkey consistent between the PDF and its notes file — that's the only link
  between them (no database, no index to keep in sync).

## Why notes, not just PDFs

A PDF answers "what does this paper say"; the notes file answers "why does this thesis cite it"
— the claim being supported, the page/section it comes from, and whether it's a citation for
data, a related-work situating claim, or a "found via" for a copied technique. That's the part
that actually needs to survive to the final report's bibliography and related-work section.
